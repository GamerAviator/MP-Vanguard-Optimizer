Gamer Aviator’s Vanguard Capture 1.0.4

EXTRACT → CLICK PLAY → IMPORT
1. Open Mighty Party in the Chrome profile for the player you want.
2. Open Vanguard Capture and click Extract this account.
3. The game reloads. Click the green Play button when it appears.
4. Keep the game open while it loads. Your VCEF capture automatically saves
   to Downloads. The extension popup can close without stopping capture.
5. In the optimizer, choose the correct account, open Import and choose your
   VCEF capture. Check the player, capture date and proposed values.
6. Select the levels/resources to apply, then Apply checked Chrome data.

INSTALL OR UPDATE
Unzip the download and keep the chrome-vanguard folder somewhere permanent.
Open chrome://extensions, enable Developer mode, choose Load unpacked and
select that folder. For updates, replace the contents of your existing folder
and click Reload on the extension card. Refresh the game tab after updating.
Pin Gamer Aviator’s Vanguard Capture using Chrome's Extensions menu.
Repeat installation in each Chrome profile you use for Mighty Party.

ACCOUNT MATCHING
Explicit game profile IDs are included when available. The optional ID field
under Troubleshooting is a fallback and applies only to that extraction.
A conflicting detected/entered ID blocks export. In the optimizer, confirm the
first profile-ID link. Future captures with that ID select its linked account.
Older captures without an ID require you to verify the destination manually.
Capturing does not change optimizer accounts. Only reviewed, checked values
change on import. Back up optimizer accounts regularly.

TROUBLESHOOTING
If Play is still visible, click it once. If no download follows, reopen the
extension and check its status. Unknown IDs, duplicate names or missing
resource balances require review under Troubleshooting before manual export.
Pyro is ID 51 and Viryel is ID 52. Diagnostics are separate from VCEF captures.

LOCAL DATA
Captures contain matched Vanguard levels, supported resource balances and
account matching information. Data is processed locally and saved as a VCEF
file. Nothing is uploaded to a server. The extension does not select Play,
simulate clicks, take screen images or make game upgrade decisions.
1.0.4 removes the experimental automatic Play feature. Automatic capture,
VCEF downloads, profile matching and optimizer review remain available.
